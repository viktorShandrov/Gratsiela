## 📌 За проекта (About the Project)

**Gratsiela Art Shop & Portfolio** е пълен e-commerce и портфолио проект, създаден специално за художника Грациела Иванова. Платформата съчетава изчистена и луксозна естетика (тъмен режим с акценти от шампанско и злато) с надеждна бекенд архитектура за онлайн търговия.

Проектът решава проблема на съвременните творци, които искат пълен контрол върху представянето и продажбите на своето изкуство без зависимост от платформени комисионни или тромави готови CMS системи (като WordPress/WooCommerce).

### 🎯 Основни цели:
- **Премиум визуално изживяване**: Галерия и представяне на картините с акцент върху детайла, текстурите, материалите и символиката.
- **Хибриден търговски модел**: Едновременна поддръжка на физически произведения (картини и принтове с доставка) и дигитални файлове (e-книги, арт ръководства и дигитални асети) със защитено автоматично изтегляне.
- **Двуезичност**: Пълна локализация на съдържанието на **български (BG)** и **английски (EN)**.
- **Пълна автоматизация**: Интеграция със Stripe за разплащания, автоматично изпращане на трансакционни имейли и защитен админ панел за управление.

## ✨ Ключови функционалности (Key Features)

### 🛍️ 1. Електронен магазин и Каталог
- **Многостепенно филтриране**: Разглеждане на артикули по категории (*Всички, Картини, Принтове, Дигитални продукти*).
- **Детайлни продуктови страници (`product.html`)**: Галерия с висока резолюция, размери, използвани материали, символика, наличност и опции за поръчка.
- **Динамична промо код система**: Поддръжка на процентни и фиксирани отстъпки с проверка на валидност в реално време.

### 💳 2. Сигурни плащания и Поръчки (Stripe Checkout & Webhooks)
- **Stripe Checkout Session**: Обработка на плащания с банкови карти в защитена среда.
- **Stripe Webhook интеграция**: Асинхронно потвърждаване на поръчките веднага след успешно плащане.
- **Защитени дигитални сваляния**: Генериране на еднократни/защитени линкове за изтегляне на дигитални продукти след валидирано плащане.

### 📊 3. Цялостен Администраторски панел (`dashboard.html`)
- **Защитена автентикация**: Сигурен достъп с хеширана парола (PBKDF2 / SHA-512) и Bearer токени.
- **Управление на продукти (CRUD)**: Добавяне, редакция, скриване/деактивиране и изтриване на картини, принтове и дигитални продукти.
- **Управление на поръчки**: Преглед на статуси на плащане, клиентски данни за доставка, стойности и история.
- **Запитвания и Съобщения**: Вградена входяща поща за съобщения от формата за контакти.
- **Промо кодове & Маркетинг**: Създаване и управление на отстъпки, както и списък с абонати за бюлетин (Newsletter).
- **Динамични настройки на сайта**: Редактиране на глобални банери за намаления, промо текстове и контакти директно от панела без нужда от пренаписване на код.

### 📧 4. Автоматизирани Имейл известия (Nodemailer)
- **Потвърждение за клиента**: Красив, брандиран HTML имейл с подробности за поръчката и директен линк за сваляне при дигитални покупки.
- **Известие за артиста**: Моментален имейл до администратора за нова продажба или ново клиентско запитване.

### 🌐 5. Двуезичен интерфейс и SEO
- Превключване между Български и Английски език в реално време с запазване на предпочитанията.
- Оптимизирани мета тагове, OpenGraph споделяне, структурирани данни, `sitemap.xml` и `robots.txt`.

## 💡 Предизвикателство и решение (Challenges & Solutions)

| Предизвикателство | Решение в проекта |
| :--- | :--- |
| **1. Гъвкавост на базата данни между локална среда и облачен хостинг (Serverless / Vercel / Render / VPS)** | Разработен е адаптивен слой за данни (`database.js`), който автоматично превключва между **PostgreSQL** (при наличие на `POSTGRES_URL`) и оптимизирана **Local JSON Data Store** (`db.json`). Това позволява нулево начално конфигуриране за локално тестване и висок клас мащабируемост в продукция. |
| **2. Защита на платеното дигитално съдържание** | Файловете за изтегляне не са публично достъпни като статични ресурси. Сървърът верифицира състоянието на поръчката чрез уникален `orderId` / `session_id` и стриймва файла сигурно чрез `Readable` поток само след успешно потвърдено плащане. |
| **3. Надеждност при плащания без загуба на поръчки** | Внедрен е Stripe Webhook слушател с Raw Body валидация на сигнатурата. Дори потребителят да затвори браузъра си преди пренасочването към страницата за успех, бекендът автоматично маркира поръчката като платена и задейства изпращането на имейл. |
| **4. Защитен и лек админ достъп без тежки външни зависимости** | Използване на криптографски сигурно хеширане с `crypto.pbkdf2Sync` (1000 итерации, SHA-512 със случаен salt), поддържане на сесийни токени и пълна защита на API маршрутите за управление. |

## 🛠️ Технологичен стек (Tech Stack)

### Backend
- **Node.js**: Среда за изпълнение на JavaScript код от страна на сървъра.
- **Express.js**: Лек и бърз уеб framework за RESTful API ендпоинти и обслужване на статично съдържание.
- **PostgreSQL (`pg` driver)**: Релационна база данни за продукционна среда.
- **Stripe API (v15+)**: Обработка на плащания, сесии и уебхуукове.
- **Nodemailer**: SMTP трансакционни имейли с персонализирани HTML шаблони.
- **Dotenv & CORS**: Управление на конфигурационни променливи и защита на заявките.

### Frontend
- **HTML5 & Modern Vanilla JavaScript (ES6+)**: Бърз, независим от тежки библиотеки интерфейс с максимална производителност.
- **CSS3 / Custom Design System**: Луксозна цветова палитра (Burgundy, Deep Charcoal, Champagne Gold), адаптивен грид, плавни анимации и микро-интеракции.
- **FontAwesome / Google Fonts**: Елегантна типография (*Cinzel, Cormorant Garamond, Montserrat*).

## 🚀 Инсталация и стартиране (Getting Started)

### 1. Клониране на хранилището
```bash
git clone https://github.com/viktorShandrov/Gratsiela.git
cd Gratsiela
```

### 2. Инсталиране на зависимостите
```bash
npm install
```

### 3. Конфигуриране на средата (`.env`)
Създайте `.env` файл в основната директория (можете да копирате `.env.example`):
```env
PORT=3000

# Stripe конфигурация
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# База данни (Опционално, ако липсва се използва db.json)
POSTGRES_URL=postgres://user:password@host:port/database

# SMTP Имейл конфигурация
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
NOTIFICATION_EMAIL=artist@example.com

# Парола за администраторския панел
DASHBOARD_PASSWORD=your_secure_password
```

### 4. Стартиране на приложението
```bash
# Стартиране в продукционен / локален режим
npm start
```
Отворете браузъра на `http://localhost:3000`.
